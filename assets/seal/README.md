# 篆書（小篆）の字形

ロゴの「妖幻」に使う篆書。説文解字の小篆の字形を、ウィキメディア・コモンズの
「古代漢字プロジェクト（Ancient Chinese characters project）」から取った。
どれもパブリックドメイン（テンプレート PD-ancient-script：
"This SVG representation of an ancient script is in the public domain."）。
帰属表示は不要だが、歓迎されている。

| ファイル | 元のファイル | 字 |
|---|---|---|
| onna.png | File:女-seal.svg | 女 |
| you.png | File:夭-seal.svg | 夭 |
| gen.png | File:𠄔-seal.svg | 𠄔（幻の古い字形） |
| yougen.png | 上の3つから作成 | 妖幻（妖＝女＋夭を左右に組み、線を太く均一にした） |

元のファイルは 960px の PNG で取得（upload.wikimedia.org の縮小版）。
