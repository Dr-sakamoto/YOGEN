# アメコミ表紙の分析（マーベル 1970〜90年代前半）

YŌGEN をアメコミ風にするための下調べ。対象は 1970 年ごろ〜1993 年ごろのマーベルの月刊誌の表紙。
年代と変更点はコレクター向けの資料（下の出典）による。出典どうしで月が食い違うところは「ごろ」と書いた。
面積の割合は、よくある構成を目で測った**目安**で、実測ではない。

> 実物の表紙・ロゴ・キャラクターは素材として使わない（CLAUDE.md の画像の決まり）。ここで借りるのは「型」だけ。

## 1. 画面の骨組み

米国のコミック誌の判型はおよそ 6⅝ × 10³⁄₁₆ インチ（縦横比 約 1:1.54）。ショート動画（9:16 = 1:1.78）より少し寸詰まり。

```
┌──────┬─────────────────────────┐
│コーナー│   題字（ロゴ）              │ ← 上 20〜30%
│ボックス│   + 冠の語 THE AMAZING など   │
├──────┴─────────────────────────┤
│  煽り文（キャッチ）                  │ ← 題字の下か絵の上に 1〜2 行
│                                 │
│        絵（アクション・対決）          │ ← 55〜70%
│        登場人物のフキダシ            │
│                                 │
├──────┐                          │
│バーコード│  下の煽り / 予告           │ ← 下 10〜15%
└──────┴─────────────────────────┘
```

- **左上：コーナーボックス**（幅 1/5〜1/6、高さ 1/8 ほど）。価格・号数・月・主役の小さな顔絵。
- **上段：題字**。横幅いっぱい、高さは表紙の 1/5〜1/4。立体文字・遠近のついた文字が多い。
- **中段：絵**。表紙の 6 割以上。人物が題字やボックスにかぶって前に出ることがよくある。
- **左下：バーコード**（1976 年ごろから）。下端の左に縦長の白い箱。

文字の面積（題字＋ボックス＋煽り＋フキダシ）は合わせて**表紙のおよそ 30〜40%**。
70 年代のほうが煽り文とフキダシが多く、80 年代後半〜90 年代前半は文字が減って絵が大きくなる。

## 2. 商業的な部品（年代順）

| 時期 | 部品 | 中身 |
|---|---|---|
| 60 年代〜 | コーナーボックス | 左上の四角に主役の絵、「MARVEL COMICS GROUP」、価格。マーベルの見分けの印。 |
| 70 年代 | 上端の帯 | 表紙の上に「MARVEL COMICS GROUP」の細い帯が付く号が多い。 |
| 70 年代 | コミックス・コードの印 | 「APPROVED BY THE COMICS CODE AUTHORITY」の切手のような小さな四角。70 年代は右上の号が多い。 |
| 1976 年 6 月号ごろ〜 | UPC バーコード | 新聞スタンド（ニューススタンド）売りの号に入る。左下。 |
| 1976 年 4〜8 月 | 価格テスト | 25¢ の号の一部を 6 つの地域で 30¢ にして売った。ボックスの価格だけが違う。 |
| 1979 年 5〜6 月号ごろ〜 | 直販版の目印 | 専門店（ダイレクトマーケット）向けは返品できないので、バーコードの箱を空けたり斜線を引いたりして区別。 |
| 1980 年 2 月号ごろ〜 | スパイダーマンの顔 | 直販版のバーコードの位置にスパイダーマンの顔の絵。 |
| 1982 年ごろ〜 | 大きな M | 直販版のボックスに大きな「M」。 |
| 80 年代後半〜90 年代前半 | ボックスの簡略化 | マーベルの斜体ロゴ、のちに四角い「Big M」のロゴ。最後はロゴ・号数・月・価格だけになる。 |

価格の推移（目安）：20¢（1972）→ 25¢（1974）→ 30¢（1976）→ 35¢（1977）→ 40¢（1979）→ 50¢（1980）→ 60¢（1981）→ 65¢（1984）→ 75¢（1986）→ $1.00（1989）→ $1.25（1992）。
価格は大きく「30¢」「60¢」と書き、ボックスの中で一番目立つ文字になっていることが多い。

## 3. タイポグラフィ

- **題字（ロゴ）**：太いサンセリフの手描き。立体の押し出し、遠近（奥に向かって小さくなる）、縁取り 2 重。
  シリーズごとに固定で、毎号同じ位置。色は号ごとに変わる。
- **冠の語**：題字の上か左に小さく「THE AMAZING」「THE MIGHTY」「THE INVINCIBLE」「THE UNCANNY」。
  題字の 1/4〜1/3 の大きさで、筆記体やイタリックにして題字と書体を変える。
- **煽り文**：手描きの大文字のみ。太い斜体、最後は「!」。黄色や白の箱、ギザギザの爆発形、旗（リボン）の形に入れる。
- **フキダシ**：表紙の人物がしゃべる。コミックの本文と同じ手書きの大文字で、強調語だけ太字。
- **号数・月**：ボックスの中に小さく「No. 129 / OCT」。号数の大きい記念号は「#100」を大きく出す。
- 文字はほぼすべて**大文字**。小文字は筆記体の冠の語くらい。

## 4. 文言の型

| 型 | 例（作り例。実在の表紙の文言ではない） |
|---|---|
| 呼び込み | 「IN THIS ISSUE:」「INTRODUCING…」「BEGINNING A NEW SAGA!」 |
| 記念・特別 | 「SPECIAL ANNIVERSARY ISSUE!」「GIANT-SIZE!」「DOUBLE-SIZED!」「COLLECTOR'S ITEM #1」 |
| 死・決着 | 「THE DEATH OF ___!」「THE FINAL BATTLE!」「THIS IS THE END!」 |
| 対決 | 「___ VS. ___!」「AT LAST — ___ MEETS ___!」 |
| 問いかけ | 「WHO IS ___?」「CAN ANYONE STOP ___?」 |
| 読者への念押し | 「YOU WON'T BELIEVE ___!」「DON'T MISS IT!」「NOW IT CAN BE TOLD!」 |
| 予告 | 「NEXT: ___!」「CONTINUED FROM LAST ISSUE!」 |

`!` と `—`（ダッシュ）と `…` を多用する。文はたいてい 6 語以内で、名詞と感嘆で終わる。

## 5. YŌGEN に持ち込むなら（案）

- **コーナーボックス**：左上に篆書の「妖幻」、回の番号（No. 07 など）、時代（EDO 1830s など）。価格の代わりに年代を一番大きく。
- **題字**：小文字の yōgen を藤黄の地に黒（ブランドの決まりどおり）。立体の押し出しは墨。
- **煽り文**：その回の妖怪名＋感嘆。事実は `research_notes` からだけ取る。「〜という説がある」系の話を煽りの看板にしない。
- **バーコード**：左下に飾りの UPC 風の縞（数字は回の ID や年代にする。本物の UPC 番号は使わない）。
- **コードの印**：「APPROVED BY THE COMICS CODE AUTHORITY」の代わりに自前の印（例「PUBLIC DOMAIN / VERIFIED」）。実在の機関の印は真似ない。
- 網点・切り抜き素材は今のレシピのまま。アメコミの網点（ベン・デイ・ドット）とも相性がいい。
- 9:16 に合わせるなら、骨組みの縦を伸ばして絵の部分を広げる（題字とボックスの大きさは横幅基準のまま）。
