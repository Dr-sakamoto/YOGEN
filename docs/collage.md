# コラージュの方針

## 充足感を保つ（2026-11-25）

- 画面は隙間なく満たす。下地（墨や染織品）を敷いて埋めた気にならない。物そのもので埋める。
- 物の個数ではなく「埋まった割合」を目標にして、いちばん空いている場所に置いていく（`src/yogen/photo_collage.py`）。
- 主役と密度は両立させる。主役の場所を先に取り、最前面に出す。残りは大きさの段（中・小）で詰める。
- 今後タイトルやエフェクトが入ると写真の数は減る。それでも充足感は保つ。題字や色面も「埋める側」として数える
  （`generate(reserve=...)` で場所を先に取る）。

写真だけの版：`yogen photo-collage --seed 3`（`out/photo/` に書き出す）。
